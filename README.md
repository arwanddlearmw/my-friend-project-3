# PC Specs Evaluator — Web Version

افتح `index.html` مباشرة في المتصفح.

النسخة الحالية تحول الجزء الظاهر من كود Android إلى:
- PC / Laptop / Phone
- إدخال المواصفات
- تقييم محلي
- حفظ الأجهزة في localStorage
- تحميل وحذف الأجهزة المحفوظة
- نافذة About
- دعم RTL/LTR وتبديل العربية/الإنجليزية

ملاحظة: منطق `SpecsViewModel` لم يكن ضمن الأكواد المرسلة، لذلك تم إنشاء منطق تقييم محلي بسيط بدلاً من ادعاء تحويل ViewModel غير موجود.
كما أن Gemini/AI الحقيقي يحتاج Backend لحماية API key.
